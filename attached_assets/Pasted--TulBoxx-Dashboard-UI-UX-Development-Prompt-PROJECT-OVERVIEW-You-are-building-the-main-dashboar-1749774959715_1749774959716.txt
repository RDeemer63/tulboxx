## TARGET AUDIENCE & DESIGN PHILOSOPHY

### User Profile
- **Primary users**: Blue-collar service professionals (contractors, HVAC techs, plumbers)
- **Demographics**: Predominantly male, mobile-first usage, work-glove friendly interfaces
- **Environment**: Outdoor job sites, varying lighting conditions, mobile devices in trucks/vans
- **Priorities**: Trust, efficiency, innovation - professional tool that can handle their workload

### Design Principles
- **Professional appearance**: Looks like premium business software, not consumer apps
- **High contrast**: Readable in bright outdoor conditions
- **Large touch targets**: Usable with work gloves
- **Mobile-first**: Responsive design prioritizing mobile experience
- **Action-oriented**: Clear CTAs and business intelligence

## RESPONSIVE BEHAVIOR

### Breakpoints
```css
/* Mobile */
@media (max-width: 768px) {
  - Quick Actions: 2x2 grid
  - Pipeline: Horizontal scroll
  - Business Metrics: 1 column
  - Bottom Section: 1 column
}

@media (max-width: 480px) {
  - Quick Actions: 1 column
  - Pipeline stages: Smaller padding
  - All metrics: Full width
}
```

### Touch Targets
- Minimum 44px height for all interactive elements
- Padding: 12-24px for comfortable thumb/glove interaction
- Hover states with 2-4px lift animation

## INTERACTIVE STATES

### Hover Effects
```css
.action-card:hover {
  transform: translateY(-4px);
  box-shadow: 0 8px 32px rgba(249, 115, 22, 0.3);
  border-color: var(--accent-orange);
}
```

### Button States
- **Default**: Orange gradient background
- **Hover**: Darker orange gradient + translateY(-1px)
- **Active**: Slightly compressed scale(0.98)

### Theme Toggle
- **Dark mode**: Moon icon visible
- **Light mode**: Sun icon visible
- **Transition**: Smooth 0.3s ease transition
- **Storage**: Use in-memory variable (no localStorage in artifacts)
